# AHUT 安徽工业大学晚寝自动签到 (AHUT Auto Check-In)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Python](https://img.shields.io/badge/Python-3.9%20%7C%203.12-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/Platform-Python%20%7C%20Tampermonkey-brightgreen.svg)]()

专为**安徽工业大学（AHUT）学生考勤系统**打造的自动化签到工具。

本项目提供 **Python 脚本**与**油猴脚本**两套独立实现方案。

---

## 方案介绍

### Python 脚本

基于协议接口交互的轻量自动化签到方案，适用于无需浏览器图形界面的无头调度与定时任务环境：

- **协议层无头签到**：通过统一认证接口获取凭据，动态提取当期最新有效考勤任务与基准定位；
- **拟真 GPS 抖动算法**：在寝室基准经纬度基础上进行随机抖动，防范风控识别；
- **多账号并发支持**：基于 `asyncio` 与 `aiohttp` 异步高并发架构，支持批量多学号并发打卡；
- **多通道分级通知**：
  - **日常结果推送**：支持通过 [Server 酱·Turbo 版](https://sct.ftqq.com/) 推送每日详细微信打卡图文报表；
  - **异常强穿透告警**：支持 [ntfy.sh](https://ntfy.sh) 官方规范，仅在打卡失败或未完全成功时触发最高优先级（Priority 5）夜间免打扰穿透响铃。

### 油猴脚本

基于真实桌面浏览器环境与 Tampermonkey 扩展的用户脚本方案，适用于在个人电脑浏览器内进行会话适配与安全打卡：

- **桌面端会话适配**：在桌面浏览器中自动提取 PC 端（`/index/`）登录凭证并注入移动端 uni-app 5 键本地存储规范，实现免扫码访问移动端考勤；
- **真实页面交互导航**：会话就绪后直达晚寝列表页（`/wise/pages/ssgl/wqqd`），监听页面渲染并受控单次点击任务卡片进入签到页；
- **Vue 实例与定位智能监听**：深度监听 Vue 实例数据与真实定位就绪时序，具备 DOM 预渲染防护与定位超范围阻断；
- **严格状态机与双模式守卫**：
  - 支持 `Run`（全自动提交）与 `Check`（只读核查状态，零业务写入）双模式；
  - 具备终态锁死、操作代次校验、防并发与防重复提交守卫；已签到时显示 `🎉 今日已签到` 并安全退出；
- **常驻悬浮看板与脱敏诊断**：页面右下角常驻可视化 HUD 控制面板，支持一键安全终止与一键复制结构化脱敏诊断信息。

## Python 脚本部署方向参考

| 分类      | 部署方向                                                            | 说明与特点                               |
| :------ | :-------------------------------------------------------------- | :---------------------------------- |
| **推荐**  | 华为云函数工作流部署（免费、准时）                                               | 利用 FunctionGraph 与 TIMER 触发器托管运行。   |
| **推荐**  | 私有 VPS 部署                                                       | 部署于个人云服务器，自主稳定。                     |
| **推荐**  | 个人电脑运行                                                          | 本地定时任务或按需手动运行，环境可控。                 |
| **推荐**  | AWS Lambda + EventBridge Scheduler（免费、免实名）                      | 利用 AWS Lambda 与 EventBridge 调度托管运行。 |
| **推荐**  | Azure Functions + Timer Trigger（免费）                             | 利用 Azure Functions 定时触发器托管运行。       |
| **推荐**  | GCP Cloud Run Functions / Jobs + Cloud Scheduler（免费，但注册可能收取预付款） | 利用 Google Cloud 算力与调度器托管运行。         |
| **不推荐** | GitHub Action（免费，有延时）                                           | 易受 GitHub 平台队列高负载影响，计划任务存在延迟。       |
| **不推荐** | 阿里云 FC（新用户三个月免费试用）                                              | 新用户仅前三个月享受免费试用额度，后续转为按量付费。          |
